# Security Policy

## Supported Versions

Currently, only the latest stable release receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

I take the security of this project seriously. If you believe you have found a security vulnerability, please do not report it via a public issue.

### Private Reporting
Please use the **[GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-confirming-vulnerabilities/reporting-a-vulnerability-in-a-repository)** feature:
1. Navigate to the "Security" tab of this repository.
2. Click on "Advisories" in the left sidebar.
3. Click "Report a vulnerability" to open a private draft advisory.

### What to Expect
- **Acknowledgement**: You can expect a response acknowledging your report within 48–72 hours.
- **Updates**: I will provide status updates at least once a week while a vulnerability is being addressed.
- **Disclosure**: Once a fix is verified and a new version is released, we can coordinate a public disclosure to credit your find.

Thank you for helping keep this project secure!
